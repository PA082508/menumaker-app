**Настоящие четыре — открыты любому залогиненному, без привязки к арендатору, ничем не удержаны:**

| **`staff`** | `auth_manage → true` — **единственная политика** | `authenticated` | **105** — персональные данные сотрудников |
| **`meal_schedule`** | `auth_manage → true` (плюс `org_isolation`, но permissive складываются по ИЛИ) | **PUBLIC** | 128 |
| **`staff_schedules`** | `auth_manage → true` — единственная | `authenticated` | 25 |
| **`dispatch_routes`** | `dr_read → true` (чтение) | `authenticated` | — |

**Намеренно публичные, не трогать:** `published_menus` (родители смотрят опубликованное меню),
`policy_documents` (чтение политик).

**Не дыры, снято с подозрения:** шесть `safepass_*` — их `USING(true)` выдан **`TO service_role`**;
`role_module_access` — **запись требует `is_org_owner(org_id)`**, то есть только Генеральный
директор. **Это НЕ путь эскалации привилегий** — вопрос владельца снят замером.

**Отдельный класс:** 24 таблицы с RLS и **нулём политик вообще** — «закрыто для всех, кроме
service_role», а не «открыто».
