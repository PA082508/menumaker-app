# Опись защит: у каких есть проба, ронявшая их, а какие мы знаем только зелёными

**Повод (Николай, 29.07):** до этого дня **ни один из четырёх гардов сборки ни разу не видел
нарушения**. Зелёный механизм — два неразличимых снаружи утверждения: «нарушений нет» и «этот
механизм не сработал бы никогда». **Гард, никогда не красневший, — гипотеза, а не защита.**

**Это список, не стройка.** Графа «гипотеза» — не обвинение и не задача на сегодня; это честная
пометка, что мы знаем о механизме только его зелёный цвет.

Опись снята **замером** 29.07: 17 триггеров и полный список RESTRICTIVE-политик прочитаны из
`pg_trigger` / `pg_policies`, не по памяти.

## B. Знаем только зелёными — ГИПОТЕЗЫ

Порядок — по последствию, не по алфавиту.

| Механизм | Что обещает | Чего нет |
|---|---|---|
| `income_org_only` (RESTRICTIVE, `enrollment_submissions`) | директор **не видит** сведений о доходе; они только у Генерального директора | никто ни разу не пробовал прочитать IEA-строку директорским логином |
| `door_read_scope` · `door_write_scope` · `door_no_insert` · `door_no_delete` (`roster`) | дверь SafePass видит **свой** центр и класс, не org | попытки прочитать чужой центр с устройства двери не делалось |

## C. Что из B просится первым, когда дойдут руки

По цене ошибки, а не по простоте:

1. **`income_org_only`** — обещание, данное владельцу отдельным решением (IEA только Генеральному
   директору). Проверяется одним `select` под директорским логином.
2. **Печать подписанного** (`seal`) — на нём стоит доказательная ценность подписи; разовая проба
   при постановке не покрывает того, что могло измениться за неделю.
3. **`door_*` на `roster`** — область двери решает, кому отдают ребёнка.
4. **Журналы `append-only`** — если правка проходит, история перестаёт быть историей, и узнать
   об этом будет неоткуда.
5. **`deny_teacher`** — общий планшет; ровно тот носитель, ради которого сужали `staff`.

**Форма пробы для базы — та же, что у послеполёта:** попытка внутри транзакции, которая в конце
намеренно падает, и отказ засчитывается **только своим текстом**.
