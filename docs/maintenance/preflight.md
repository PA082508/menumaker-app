# Предполёт

Половин у предполёта две. **Объявляемая** — [`approved-pending.md`](approved-pending.md):
одобренное, но не применённое; строка пишется в момент одобрения, и предполёт требует
объяснения по каждой незакрытой. **Обнаруживаемая** — запросы и грепы; она автоматизируется
и живёт здесь.

Слой ещё не построен (стоит в очереди). Файл ведётся **сейчас**, чтобы шаги ложились в него
по мере находок, а не вспоминались при сборке.

---

## Шаг П-1. Перед отзывом права или удалением колонки — греп ВЫЛОЖЕННОГО бандла

**Обязателен перед:** `revoke` на колонку или таблицу · `drop column` · переименование
колонки · сужение политики, отбирающее доступ у роли, под которой ходят экраны.

**Почему отдельным шагом, а не «внимательно».** Ни один из трёх этажей между «сделано» и
«работает» этого не покрывал: этаж «в базе» скажет, что право отозвано (правда), этаж
«в коде» — что запрос переписан (тоже правда), этаж «на боевом» проверяется **после**
выкладки, а отзыв права действует **до** неё и **в одиночку**. Все три зелёные, экран мёртв.

**Случай 28–29.07.** `staff.pin_hash` закрыт грантом в 03:22 UTC. Починка `select('*')` на
карточке сотрудника лежала в **незапушенном** коммите. Карточка была мертва **десять часов**
у всех до единого и показывала уверенную пустоту без ошибки.

**Как делается — по выложенному файлу, не по рабочему дереву:**

```bash
BUNDLE=$(curl -s https://menumaker-app.vercel.app/ | grep -o '/assets/[^"]*\.js' | head -1)
curl -s "https://menumaker-app.vercel.app$BUNDLE" -o /tmp/live.js

# 1. звёздочка по затрагиваемой таблице — задевает и закрываемую колонку
grep -o 'from("<таблица>").select("[^"]*"' /tmp/live.js | sort -u

# 2. прямые обращения к колонке
grep -c '<колонка>' /tmp/live.js
```

**Как читать.** `select("*")` в списке = **экран умрёт в момент отзыва**. Тогда порядок
обратный обычному: **сперва код на боевом, потом отзыв права** (канон «Форма НАОБОРОТ» в
[`platform-standards.md`](../platform-standards.md)). Рабочее дерево тут не свидетель: в нём
починка может лежать уже неделю и всё ещё не быть выложенной.

**Отрицательная половина шага.** Если греп нашёл ноль обращений — это ответ «никто не
просит», а не «проверять нечего»: убедиться, что бандл вообще скачался и непуст, иначе
пустой файл даёт зелёное на любой греп.

## Шаг П-2. Незакрытые строки одобренного

Прочитать [`approved-pending.md`](approved-pending.md) целиком и по **каждой** незакрытой
строке сказать, почему она не применена. Строка без объяснения — стоп.

## Шаг П-3. Обнаруживаемая половина

- незапушенные коммиты: `git log --oneline origin/main..HEAD`
- миграции против развёрнутого кода: `node scripts/postflight.mjs`
- незакоммиченный файл боевого реестра: `git status --short -- '*enroll-registry.json'`
- `docs/prepare/*` без применения — сверить с `supabase_migrations.schema_migrations`
