## 3. Реестр регуляторных сроков — устройство (спека)

### 3.1 Поля записи

| Поле | Смысл |
|---|---|
| `what` | что за срок, человеческим языком |
| `due` | дата (или правило: «45 дней от конца месяца») |
| `source_url` | ссылка на источник |
| `source_published_at` | **дата публикации источника** — без неё запись не принимается |
| `source_kind` | бюллетень · политика · норма CFR/OAC · слова владельца (тоже источник, с датой) |
| `applies_to` | спонсор · центр(ы) · ребёнок · сотрудник |
| `prepare` | что нужно подготовить (список документов/действий) |
| `remind_at` | когда напомнить (несколько отсечек) |
| `status` | действует · подтверждается у источника · снят |
| `verified_at` / `verified_by` | когда и кем перепроверен — **ежегодно** |
| `supersedes` | какую запись заменяет (forward-only, старая не затирается) |

**Инварианты:**

```
✅ запись без источника и даты его публикации НЕ ПРИНИМАЕТСЯ
✅ смена срока = НОВАЯ запись со ссылкой supersedes; прежняя остаётся видимой
✅ перепроверка ежегодная и датированная — «проверено» без даты не считается
❌ напоминание НЕ гейт: реестр напоминает, не блокирует работу центра
```

### 3.3 Место агента дозора

Агент дозора работает **над реестром, а не вместо него**: приносит изменение источника
(бюллетень, редакция политики) → человек решает, меняется ли срок → запись
**forward-only**. Автоматическая правка даты агентом **запрещена**: это ровно тот случай,
где ложное утверждение о сроке дороже отсутствия утверждения.

⚠️ Сегодняшний случай — доказательство нужды: сдвиг 15.11 → 15.10 нашёлся **случайно**;
по памяти о нём узнали бы **после срока**.
