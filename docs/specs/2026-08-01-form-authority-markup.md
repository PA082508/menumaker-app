# A5 · Разметка реестра: какая форма под каким органом и что можно электронно (01.08.2026)

**Назначение — гейт кампании понедельника.** Без этой разметки можно разослать электронно
форму, подпись под которой орган не признает.

## ⚠️ СТАТУС ПРОВЕРКИ — ПРОЧЕСТЬ ПЕРВЫМ

Разметка ниже — **черновик для ратификации владельцем**, а не установленный факт. Что именно
проверено:

| Утверждение | Проверено? |
|---|---|
| Состав реестра — 32 формы, их ключи, `signer`, `requires_countersign`, `auto_file` | ✅ **да**, по `public/enroll-registry.json` |
| «Разрешения CACFP на э-подпись нет» | ⚪ **со слов владельца**, документа в репозитории нет |
| «Шапка бланка DCY разрешает содержательно эквивалентную замену» | 🔴 **НЕ подтверждено**: искал в бланках репозитория формулировки *substantially similar / equivalent / may be used* — **не найдено ни одной**. Проверять по печатному бланку, а не по нашей копии |
| Отнесение конкретной формы к органу | ⚪ **мой вывод по назначению формы**, не по письму органа |

**Отсюда правило пользования:** строка «можно электронно = ДА» ниже означает
«**по нашей разметке** препятствий не видно», а не «орган разрешил».

## Три корзины

### 🔴 A. Продовольственная программа CACFP — бумага + подтверждение директора

Пока разрешения на э-подпись нет, эти формы собираются **на бумаге**, а в системе стоит
подтверждение директора (третье состояние, A2).

| Форма | Ключ | Кто подписывает | Почему сюда |
|---|---|---|---|
| Income Eligibility Application FY2026-27 | `iea` | родитель | определяет F/R/P → **деньги заявки** |
| USDA Income Eligibility Waiver | `usda_waiver` | родитель | отказ от IEA, тот же контур |
| CACFP Enrollment | `enroll` | родитель | зачисление в продовольственную программу |
| Fluid Milk Substitution Request | `fluid_milk` | родитель | замена в **меал-паттерне** CACFP |
| Infant Meal Preference | `infant_meals` | родитель | младенческий меал-паттерн CACFP |
| Special Diet Statement (medical) | `special_diet` | врач | замена меал-паттерна по медпоказанию |

⚠️ **Спорные внутри корзины A — назвать владельцу отдельно:** `fluid_milk`, `infant_meals`,
`special_diet` относятся к меал-паттерну, но **не к определению дохода**. Если запрет на
э-подпись касается только доходных форм, эти три уходят в корзину B и кампания расширяется.
**Решает владелец, не я.**

### 🟡 B. Формы штата (DCY / лицензирование) — основание другое

| Форма | Ключ |
|---|---|
| DCY 01234 — Child Enrollment & Health | `dcy_01234` |
| DCY 01236 — Care Plan (special needs) | `dcy_01236` |
| DCY 01217 — Administration of Medication | `dcy_01217` |
| JFS 01305 — Child Medical Statement | `dcy_01305` |
| DCY 01218 — Basic Infant | `dcy_01218` |
| DCY 01225 / 01226 — Routine Trip / Field Trip | `dcy_01225`, `dcy_01226` |
| Center Parent Information (Appendix 5101:2-1) | `center_parent_info` |
| Child Release Authorization | `child_release_authorization` |
| Transition into the Program | `transition_into_program` |
| Family Needs Survey (SUTQ) | `sutq_family_needs_survey` |

🔴 **Электронно — только после подтверждения формулировки в шапке печатного бланка.** В наших
копиях её нет; строить кампанию на непроверенной цитате нельзя.

### 🟢 C. Документы центра — своё основание, орган не участвует

`parents_book` · `parents_book_ack` · `start_form` · `parent_responsibilities` ·
`topical_product_consent` · `wic_information` · `building_for_the_future` ·
`what_to_bring_infant` · `center_parent_information` · `school_enrollment_regular` ·
`school_enrollment_fullday` · `parent_consent` · `staff` · `staff_consent`

**Электронно — да.** Это документы между центром и семьёй (или центром и сотрудником).

⚠️ `parent_consent` и `staff_consent` — **согласие на электронную подпись как таковую**. Они
основание для остальных, и собирать их электронно логично; но если орган не признаёт э-подпись
для корзины A, согласие её **не заменяет**.

---

## Что это значит для понедельника

```
Кампания понедельника = корзина C  (+ корзина B, если владелец подтвердит шапку бланка)
Корзина A            = бумага в сейф + подтверждение директора в системе
```

Обе формы с `auto_file=true` (`parent_consent`, `parents_book_ack`) — из корзины C.
Совпадение удачное: авто-файл и так работает только там, где орган не участвует.
